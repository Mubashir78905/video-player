Generate videos.json

Paste your folder structure below (one folder per line, videos listed underneath), or upload your existing videos.json. When you're done, click Generate, copy the JSON, and save it as videos.json in the root of your website next to index.html.

1. Paste your folder structure

Write one folder name followed by a colon, then list videos on the following lines, indented or prefixed with -. Add an optional title after a pipe |. Example: 

Movies:
  - vid1.mp4 | My First Movie
  - vid2.mp4
Learning:
  - lesson01.mp4 | Introduction
  - lesson02.mp4

Or add videos one by one (optional)

    3. How to deploy

    1. Save the generated JSON as videos.json in the root folder (next to index.html).
    2. Upload all website files (index.html, watch.html, admin.html, style.css, app.js, watch.js, admin.js, videos.json) to your hosting or GitHub Pages.
    3. Upload your video files into a folder named videos/ (with subfolders matching the folder names you used above).
    4. Optional: place a thumbnail image (e.g. vid1.jpg) next to each video — it will be used automatically if present.
    5. Open your site — folders and videos will appear automatically.
